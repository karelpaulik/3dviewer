Meshbex

CAD Explorer in your browser

Meshbex is a free web-based CAD explorer for engineers, makers, and anyone who needs to open STL, GLB, and other 3D files without login, cloud upload, or install — explore assemblies, measure, document, and export presentations on your device.

Built for exploration and documentation

One workspace for viewing, measuring, assembling and writing — everything kept inside the model file on your device.

  • No login, no cloud

    Open Meshbex and start working. No account, no uploads — your models never leave your computer. File security is never higher than when work stays only on your machine.

  • Assembly workflows

    Build step-by-step assembly and explode sequences with smooth animated playback.

  • Cross-sections

    Cut through solids to inspect internal geometry without leaving the browser.

  • Measurements & annotations

    Add dimensions, notes and labels that stay attached to the scene.

  • In-file documents

    Write documentation next to the model — text, images and attachments in one GLB file.

  • HTML export & optional PWA

    Share self-contained interactive presentations. Use Meshbex in the browser with no install, or install as a PWA for offline use.

Formats that fit CAD work

GLB is the primary Meshbex format — geometry, materials, hierarchy, assembly steps and documents in one file. Other common CAD and mesh formats are supported for import.

  • GLB / glTF
  • STL
  • OBJ
  • FBX
  • 3MF
  • STEP / STP
  • IGES / IGS

Frequently asked questions

Short answers about price, privacy, formats, and how Meshbex runs.

Is Meshbex free?

Yes. Meshbex CAD Explorer is free for everyone — no paid plan is required to view, explore, measure, or document 3D models.

Do I need an account or login?

No. Open Meshbex in your browser and start working immediately. No registration or account is required.

Are my 3D files uploaded to the cloud?

No. Your models stay on your computer. Meshbex does not upload files to Meshbex servers — work stays local on your device.

Which file formats are supported?

GLB is the primary Meshbex format. You can also import glTF, STL, OBJ, FBX, 3MF, STEP/STP, and IGES/IGS. See the supported file formats guide for details.

Do I need to install anything?

No install is required. Meshbex runs in a modern web browser. You can optionally install it as a PWA for offline use.

Can I use Meshbex offline?

Yes, after installing Meshbex as a Progressive Web App (PWA). The install is one click and does not require an admin account.
