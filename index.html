Built for exploration and documentation

One workspace for viewing, measuring, assembling and writing — everything kept inside the model file on your device.

  • No login, no cloud

    Open Meshbex and start working. No account, no uploads — your models never leave your computer. File security is never higher than when work stays only on your machine.

  • Assembly workflows

    Build step-by-step assembly and explode sequences with smooth animated playback.

  • Cross-sections

    Cut through solids to inspect internal geometry without leaving the browser.

  • Measurements & annotations

    Add dimensions, notes and labels that stay attached to the scene.

  • In-file documents

    Write documentation next to the model — text, images and attachments in one GLB file.

  • HTML export & optional PWA

    Share self-contained interactive presentations. Use Meshbex in the browser with no install, or install as a PWA for offline use.

Formats that fit CAD work

GLB is the primary Meshbex format — geometry, materials, hierarchy, assembly steps and documents in one file. Other common CAD and mesh formats are supported for import.

  • GLB / glTF
  • STL
  • OBJ
  • FBX
  • 3MF
  • STEP / STP
  • IGES / IGS
